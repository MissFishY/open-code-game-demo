# 贪吃蛇 Snake Game

一个用 Python 标准库 `tkinter` 实现的经典贪吃蛇，无需安装任何第三方依赖。

## 运行

```bash
python snake.py
```

要求：Python 3.6+（Windows / macOS / Linux 均可，需带 tkinter；
Linux 若缺失请执行 `sudo apt install python3-tk`）。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 控制蛇的方向（开局时按任意方向键即可开始） |
| `空格` | 暂停 / 继续游戏 |
| `R` 或 `回车` | 重新开始一局 |
| `H` 或 `?` | 显示 / 隐藏游戏内的操作说明面板 |
| `Q` 或 `ESC` | 退出游戏 |

## 规则

- 吃掉红色圆形食物得分 +1，蛇身变长。
- 撞到墙壁或咬到自己的身体即游戏结束。
- 不能直接 180° 掉头（例如向右移动时按 `←` 会被忽略）。
- 每吃 5 个食物速度提升一级（最快间隔 60ms/步）。
- 最高分保存在同目录下的 `snake_highscore.txt`。

## 可调参数

修改 `snake.py` 顶部的常量即可：

```python
CELL = 20          # 格子边长（像素）
COLS, ROWS = 30, 20   # 棋盘列数 / 行数
START_DELAY = 140  # 初始每步间隔(毫秒)，越小越快
MIN_DELAY = 60     # 最快速度
SPEED_STEP = 4     # 每吃 5 个食物提速的毫秒数
```
